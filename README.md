# PPG Bluetooth Heart Rate Monitor with GUI

**Biomedical Engineering | University of Sydney | 2024**

## Overview
A Bluetooth-enabled photoplethysmography (PPG) heart rate monitor with a real-time GUI, integrating hardware signal acquisition with software signal processing and display.

## Technical Approach
- PPG sensor interfacing and signal acquisition via Arduino
- Bluetooth transmission of real-time heart rate data
- Python-based GUI for live signal display and processing
- C++ firmware for embedded signal handling

## Repository Contents
- `firmware/` - Arduino and C++ source files
- `gui/` - Python GUI scripts

## Tools & Technologies
`Arduino` `C++` `Python` `Bluetooth` `Signal Processing` `GUI Development`
